# Icees Visuals (Fabric 1.21.1)

Sakura-styled Minecraft visuals client mod.

## Features
- **Orbit menu** — Right Shift (skies, cosmetics, knives, effects)
- **8 living skies** — Sakura, Galaxy, Aether, Nocturne, Amethyst, Opaline, Rain, Fire
- **Cosmetics** — wings, halos, capes, aura, jump circles
- **Knife animations** — 8 styles with inspect / flip style motion (first person)

## Build
```bash
./gradlew build
```
Jar output: `build/libs/icees-visuals-1.0.0.jar`

## Install
1. Fabric Loader + Fabric API for Minecraft 1.21.1
2. Drop the jar into `.minecraft/mods`
