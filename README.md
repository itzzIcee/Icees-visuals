# Icees Visuals

Sakura-styled Minecraft visuals client — living skies, cosmetics, knife animations, and an Orbit menu (Right Shift).

## Minecraft mod (Fabric 1.21.1)

```bash
cd mod
./gradlew build
```

Jar: `mod/build/libs/icees-visuals-1.0.0.jar`

Needs **Fabric Loader** + **Fabric API** for Minecraft **1.21.1**.

### In game
- **Right Shift** opens Orbit (Skies / Cosmetics / Knives / Effects)
- 8 skies: Sakura, Galaxy, Aether, Nocturne, Amethyst, Opaline, Rain, Fire
- Wings, halos, capes, aura, jump circles
- First-person knife animations (8 styles)

## Landing page

```bash
npm install
npm run dev
```
